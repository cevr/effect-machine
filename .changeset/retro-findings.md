Five fixes from a consumer audit.

- **Breaking:** `machine.task` now requires a handler when the task needs one (#95). It requires `onSuccess` unless every value that `run` succeeds with is already a machine event. It requires `onFailure` unless `run` cannot fail. A task that omitted a needed handler compiled before: it sent a non-event value as an event, or turned a typed failure into a defect. Migration: add the named handler. Or make the failure a defect with `Effect.orDie` in `run`. Or map the value to an event in `run`. Three more calls stop compiling. An options value whose type declares a needed handler optional (`onFailure?`) or `| undefined` must declare it as required. A run with error type `any` needs `onFailure`. Explicit type arguments on `task` no longer match an overload: remove them.
- **Breaking:** `ActorHost.host` now returns `Effect<ActorRef, never, Scope>` (#94). A typed factory failure reaches consumers through `acquire`, and the `host` wait parks until its own generation closes. A factory cause with a defect or an interruption still ends `host`, its typed failures made defects with their annotations kept. If that cause holds a defect, or a typed failure and an interruption, the parent ends with a `Defect` lifecycle. A cause made only of interruptions ends the spawn, and the parent stays in its state. A `host` call on a closed host service dies with `ActorHostClosedError`, and an overlapping `host` dies with `ActorHostOccupiedError`. Migration: replace `actors.host(lease).pipe(<policy>)` with `actors.host(lease)`.
- `machine.spawn(state, handler, { name })` sets the name that `Machine.definition` reports (#96). An `Effect.fn` handler or an inline arrow has no function name, so its spawn reported `undefined` before. `SpawnEffectOptions` is exported.
- For an actor that effect-machine spawns, `ActorAtom.make`, `ActorAtom.lifecycle` and `ActorAtom.latestTransition` return the same Atom for every call with one actor (#97). They read shared source Atoms for state, lifecycle and latest transition. Each source holds one actor subscription for each registry that mounts it, so render code needs no memo for `make`, `lifecycle` and `latestTransition`. `ActorAtom.can` Atoms and `Atom.withLabel` copies add no subscription. The actor ref holds the shared Atoms, so the cache adds no global root.
- `actor.can`, `actor.client.can`, `actor.client.canSync`, `actor.sync.can` and `ActorAtom.can` answer `false` once the actor is final, stopped or defected, and run no predicate then (#98). They answered from the last state before.
